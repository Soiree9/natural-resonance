# Implementation Contract

## 目标

迁移“章节式停靠 + 电影镜头推进 + Canvas 产品叙事”的动效感，载体为原生 HTML、CSS、JavaScript 与 Canvas。实现不依赖参考站源码、品牌或资产。

## 代表性记忆点

`02 — Air in the Body`：镜头贴近单 F 孔，暖光沿木纹和孔边掠过，随后稳定停靠。

## 运行接口

- `MEDIA.mobile`：竖版素材、分辨率和加载清单。
- `STATIONS`：章节 ID、时长、停靠图、双语文案和转场策略。
- 状态：`loading → ready → playing → settled → error`。
- 所有画面、文案、导航、声音和输入锁均由同一状态派生。

## 视口

- 主目标：390×844 手机竖屏。
- 兼容检查：768×900、1280×720、1440×900。
- 宽屏保留竖版电影画幅，周边使用同源暗色虚化，不拉伸产品图。

## 素材策略

v1 使用三张独立竖版原创产品图；第四章回到第一章英雄图。相邻章节通过 Canvas 缩放、平移、曝光压暗和交叉淡化建立连续机位感。用户提供的即梦 MP4 仅存放在公开目录之外，未被站点引用或提交。

## 已知差异

最初方案中的桌面帧序列与八段外部视频被移动端赶工范围替代；站点现在无需付费视频服务即可完整运行。
