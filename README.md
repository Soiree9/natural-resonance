# NATURAL RESONANCE

一个手机优先的电影感半空心电吉他展示站。封面先沿同一张真实整琴照片从琴身底部移动到琴头，四个章节再由同一套 Canvas 状态机驱动，通过高清产品照片、镜头推进、曝光掠光与颗粒形成连续的结构介绍。

## 本地运行

```powershell
npm.cmd run check
npm.cmd run serve -- --port 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 交互

- 点击 `开始体验 / ENTER` 进入。
- 上下滑动、滚轮、方向键、PageUp/PageDown、Enter 或空格逐章移动。
- 系统开启“减少动态效果”时，章节改用短交叉淡化。

## 运镜边界

- 镜头按“整琴显形 → 推近 F 孔 → 横移拾音与琴桥 → 三次外观件对焦 → 拉远琴头”连续运行。
- 封面另有一段“琴身底部 → 琴颈 → 琴头”的固定镜头路线；它使用旋转后的官方整琴主图，不是推断出的三维模型。
- 产品层不再裁切在内层竖版矩形中；超出画面的部分由浏览器边缘自然取景，外围只使用同一张实拍的暗化模糊层补光。
- 第三、第四章的高清主体在照片边缘逐渐融入同源模糊背景，避免出现完整矩形图片被塞进画面的边界。
- 鼠标与触控反馈采用 Fender 351 白色珍珠纹拨片实拍裁样；触控时拨片短暂显示在手指上方。
- 当前没有独立零件实拍或真实三维模型，因此不制作会暴露虚构背面、内部线路或安装结构的爆破图。完整动态约束见 `MOTION-CONTRACT.md`。
