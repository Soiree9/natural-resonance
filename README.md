# NATURAL RESONANCE

一个手机优先的电影感半空心电吉他展示站。四个章节由同一套 Canvas 状态机驱动，通过原创竖版产品图、镜头推进、曝光掠光、颗粒与声音反馈，形成连续的产品叙事。

## 本地运行

```powershell
npm.cmd run check
npm.cmd run serve -- --port 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 交互

- 点击 `ENTER THE RESONANCE` 进入。
- 上下滑动、滚轮、方向键、PageUp/PageDown、Enter 或空格逐章移动。
- 声音默认关闭；开启后使用 Web Audio 在本地合成提示音，不请求外部音乐。
- 系统开启“减少动态效果”时，章节改用短交叉淡化。
