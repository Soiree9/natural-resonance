# M03 — Touch the Signal / Mobile

## 即梦设置

- 模型：即梦 Seedance 2.5
- 模式：首尾帧
- 首帧：`01-first-frame.png`
- 尾帧：`02-last-frame.png`
- 比例：9:16
- 清晰度：720P；如果有更高档位就选最高档
- 时长：4s
- 运动设置：自动
- 生成数量：赶时间可一次生成 3 个候选
- 提示词：完整复制 `prompt.txt`

## 回传文件

下载原始 MP4，命名为：

`M03-touch-the-signal-mobile-take01.mp4`

如果一次生成三条，依次命名 `take01`、`take02`、`take03`，全部交回。

## 合格标准

- 一个连续镜头，没有跳剪、黑场或镜像。
- 两枚拾音器、四个旋钮和六根琴弦数量不变。
- 拾音器、琴桥和旋钮没有融化或漂移。
- 高光短促克制，不出现大面积闪烁。
- 尾帧稳定落到给定五金构图。
